# US-005: Run a timer

**Feature**: FEAT-003 — Time Tracking
**Feature Requirements**: see FEAT-003
**PRD Requirements**: FR-7, FR-11
**Priority**: P0

## Story

**As a** Priya, Member
**I want** to start and stop a timer on a project and task
**So that** I do not reconstruct hours later

## Context

The timer start time is held on the server so it survives reloads and device changes.

## Walkthrough

1. User picks project and task and starts the timer
2. User reloads the page
3. System still shows the running timer
4. User stops it and adds a note
5. System saves an entry

## Acceptance Criteria

- [ ] **US-005-AC1** — Given no running timer, when the user starts a timer on project A, then A shows as running
- [ ] **US-005-AC2** — Given a timer running on A, when the user starts a timer on B, then A stops and saves its entry and only B runs
- [ ] **US-005-AC3** — Given a running timer, when the page reloads or another device opens Tempo, then the same timer and elapsed time show

## Edge Cases

- Timer over 12 hours: user prompted to confirm duration on stop.
