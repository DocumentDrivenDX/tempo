# US-007: Set a project budget and watch it

**Feature**: FEAT-004 — Budgets and Rates
**Feature Requirements**: see FEAT-004
**PRD Requirements**: FR-12, FR-14
**Priority**: P1

## Story

**As a** Marcus, Project Manager
**I want** to set an hours and dollar budget with an alert
**So that** I see overruns before they happen

## Context

Budget burn drives staffing and client conversations.

## Walkthrough

1. Manager sets 200 hours and an 80% alert
2. Time is logged
3. Project page shows consumed and remaining
4. Alert flags at 80%

## Acceptance Criteria

- [ ] **US-007-AC1** — Given a project with a 200 hour budget, when logged hours reach 160, then the project is flagged at its alert threshold
- [ ] **US-007-AC2** — Given a project over budget, when a viewer opens it, then it is marked exceeded

## Edge Cases

- No budget set: no consumption bar shown.

## Test Scenarios

| Scenario | AC ID | Input / State | Action | Expected Result |
|----------|-------|---------------|--------|-----------------|
| Happy path | US-007-AC1 | a project with a 200 hour budget | logged hours reach 160 | the project is flagged at its alert threshold |
| Case 2 | US-007-AC2 | a project over budget | a viewer opens it | it is marked exceeded |
