# US-013: Export a report to CSV

**Feature**: FEAT-006 — Reports and Export
**Feature Requirements**: see FEAT-006
**PRD Requirements**: FR-20
**Priority**: P0

## Story

**As a** Alex, Admin
**I want** to export the report I am viewing
**So that** I can hand it to billing

## Context

The export must match the screen so numbers agree everywhere.

## Walkthrough

1. Admin runs a report
2. Admin selects export
3. System downloads a CSV

## Acceptance Criteria

- [ ] **US-013-AC1** — Given a report on screen, when an Admin exports, then the CSV rows and totals equal the screen for the same filters
- [ ] **US-013-AC2** — Given an empty report, when an Admin exports, then a header-only CSV downloads

## Edge Cases

- Large exports (5 years): complete within the function time limit or are chunked.

## Test Scenarios

| Scenario | AC ID | Input / State | Action | Expected Result |
|----------|-------|---------------|--------|-----------------|
| Happy path | US-013-AC1 | a report on screen | an Admin exports | the CSV rows and totals equal the screen for the same filters |
| Case 2 | US-013-AC2 | an empty report | an Admin exports | a header-only CSV downloads |
