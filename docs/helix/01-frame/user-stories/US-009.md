# US-009: Find entries awaiting approval

**Feature**: FEAT-005 — Entry Approval
**Feature Requirements**: see FEAT-005
**PRD Requirements**: FR-15
**Priority**: P0

## Story

**As a** Marcus, Project Manager
**I want** to see the entries on my projects that are pending approval
**So that** I can approve without chasing anyone

## Context

Entries are pending from the moment they are logged; there is no submit step, and weeks are only a view.

## Walkthrough

1. Manager opens the approval queue
2. System lists pending, stopped entries on projects they manage
3. Manager filters by user, project, and date range

## Acceptance Criteria

- [ ] **US-009-AC1** — Given entries logged on projects A and B, when the Manager of A opens the queue, then only pending entries on A are listed
- [ ] **US-009-AC2** — Given a running timer on A, when the Manager opens the queue, then the running entry is not listed
- [ ] **US-009-AC3** — Given a Manager filtering by user and date range, when they apply the filter, then only matching pending entries show

## Edge Cases

- Project with no Manager: Admins see its pending entries.
