# US-009: Submit my week

**Feature**: FEAT-005 — Timesheet Approval
**Feature Requirements**: see FEAT-005
**PRD Requirements**: FR-15
**Priority**: P0

## Story

**As a** Priya, Member
**I want** to submit my week for approval
**So that** my hours can be approved and locked

## Context

Submission closes the editing window while managers review.

## Walkthrough

1. User reviews the week
2. User submits
3. System marks entries submitted and read-only

## Acceptance Criteria

- [ ] **US-009-AC1** — Given a week with entries, when the user submits, then entries are submitted and read-only to the user
- [ ] **US-009-AC2** — Given a submitted week, when the user tries to edit an entry, then the edit is refused

## Edge Cases

- Empty week: submission refused with message.

## Test Scenarios

| Scenario | AC ID | Input / State | Action | Expected Result |
|----------|-------|---------------|--------|-----------------|
| Happy path | US-009-AC1 | a week with entries | the user submits | entries are submitted and read-only to the user |
| Case 2 | US-009-AC2 | a submitted week | the user tries to edit an entry | the edit is refused |
