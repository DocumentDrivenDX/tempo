# US-003: Create a project and add members

**Feature**: FEAT-002 — Projects and Tasks
**Feature Requirements**: see FEAT-002
**PRD Requirements**: FR-4, FR-5
**Priority**: P0

## Story

**As a** Alex, Admin
**I want** to create a project and assign Managers and Contributors
**So that** the right people can log and approve time

## Context

Projects are the unit of time, budget, and approval.

## Walkthrough

1. Admin creates a project with name, client, billable default
2. Admin adds members with roles
3. Members see the project

## Acceptance Criteria

- [ ] **US-003-AC1** — Given an Admin, when they create a project and add Priya as Contributor, then Priya sees the project
- [ ] **US-003-AC2** — Given an archived project, when a member starts a timer on it, then the action is refused

## Edge Cases

- Duplicate project name for the same client: warned.
