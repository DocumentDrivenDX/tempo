# US-002: Members see only their projects

**Feature**: FEAT-001 — Identity and Access
**Feature Requirements**: see FEAT-001
**PRD Requirements**: FR-3
**Priority**: P0

## Story

**As a** Priya, Member
**I want** to only see projects I belong to
**So that** other projects stay private

## Context

Authorization must hold on the server, not just the UI.

## Walkthrough

1. Member lists projects
2. System returns only memberships
3. Member requests another project directly
4. System denies

## Acceptance Criteria

- [ ] **US-002-AC1** — Given a Member not in project P, when they request P by identifier, then access is denied
- [ ] **US-002-AC2** — Given an Admin, when they list projects, then all projects appear

## Edge Cases

- Deactivated user with a valid token: denied.

## Test Scenarios

| Scenario | AC ID | Input / State | Action | Expected Result |

| Happy path | US-002-AC1 | a Member not in project P | they request P by identifier | access is denied |
| Case 2 | US-002-AC2 | an Admin | they list projects | all projects appear |
