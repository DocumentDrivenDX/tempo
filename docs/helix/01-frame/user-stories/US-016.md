# US-016: See when people work

**Feature**: FEAT-006 — Reports and Export
**Feature Requirements**: see FEAT-006
**PRD Requirements**: FR-26
**Priority**: P0

## Story

**As a** Alex, Admin
**I want** to report hours by local day and by time of day
**So that** I understand working patterns and month-end totals

## Context

Local-time reporting needs the recorded zone, not UTC.

## Walkthrough

1. Admin opens the time-of-day report
2. System groups entries by hour in each entry local time
3. Admin switches month grouping to a chosen reporting zone

## Acceptance Criteria

- [ ] **US-016-AC1** — Given entries logged in two time zones, when an Admin runs the time-of-day report, then hours group by each entry local hour
- [ ] **US-016-AC2** — Given an entry on 31 May 23:00 local that is 1 June in UTC, when an Admin reports by month using local dates, then the entry counts in May
- [ ] **US-016-AC3** — Given an Admin choosing one reporting zone, when they run the monthly report, then entries are bucketed by that zone

## Edge Cases

- Entries without a start time are excluded from the time-of-day view and counted in day totals.
