# US-001: Sign in with Entra ID

**Feature**: FEAT-001 — Identity and Access
**Feature Requirements**: see FEAT-001
**PRD Requirements**: FR-1, FR-2
**Priority**: P0

## Story

**As a** Priya, Member
**I want** to sign in with my company account
**So that** I never manage another password

## Context

Priya opens Tempo for the first time and needs to be recognized as a Member without registering.

## Walkthrough

1. User opens Tempo
2. System redirects to Entra sign-in
3. User authenticates
4. System creates the user on first sign-in and shows the timesheet

## Acceptance Criteria

- [ ] **US-001-AC1** — Given an unauthenticated visitor, when they open Tempo, then they are redirected to Entra sign-in and no data is returned
- [ ] **US-001-AC2** — Given a new Entra user with no app role, when they sign in for the first time, then a Member user is created and the app opens
- [ ] **US-001-AC3** — Given a user with the Admin app role, when they sign in, then they have Admin rights

## Edge Cases

- Tenant guest account: sign-in refused.
