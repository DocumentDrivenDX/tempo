# US-012: Run an hours report

**Feature**: FEAT-006 — Reports and Export
**Feature Requirements**: see FEAT-006
**PRD Requirements**: FR-19, FR-21
**Priority**: P0

## Story

**As a** Alex, Admin
**I want** to report hours by project, user, task, or day
**So that** I can answer where hours went

## Context

Reports serve billing, budget reviews, and payroll inputs.

## Walkthrough

1. Admin picks a date range and grouping
2. System shows hours and amounts
3. Admin filters billable only

## Acceptance Criteria

- [ ] **US-012-AC1** — Given entries in May across projects, when an Admin groups by project for May, then hours per project show with totals
- [ ] **US-012-AC2** — Given a Member, when they run a report, then only their own hours show and no rates or amounts
- [ ] **US-012-AC3** — Given a project Manager, when they run a report, then amounts show for their projects only

## Edge Cases

- Empty range: empty report.
