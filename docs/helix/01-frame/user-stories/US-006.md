# US-006: Add and edit entries by hand

**Feature**: FEAT-003 — Time Tracking
**Feature Requirements**: see FEAT-003
**PRD Requirements**: FR-8, FR-9, FR-10
**Priority**: P0

## Story

**As a** Priya, Member
**I want** to add or fix entries in my week view
**So that** my hours are accurate before a manager approves them

## Context

Forgotten time is the main cause of late logging.

## Walkthrough

1. User opens the week view
2. User adds an entry for Tuesday
3. User edits a duration
4. Totals update

## Acceptance Criteria

- [ ] **US-006-AC1** — Given a user in the week view, when they add 90 minutes on Tuesday for project A, then the entry saves and totals update
- [ ] **US-006-AC2** — Given an approved entry, when the user tries to edit it, then the edit is refused and the entry is unchanged
- [ ] **US-006-AC3** — Given an unapproved entry, when the user deletes it, then it is removed and totals update

## Edge Cases

- Zero or negative duration: rejected.
- Entry date in the future: rejected.
