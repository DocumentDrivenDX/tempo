# US-008: Set billable rates

**Feature**: FEAT-004 — Budgets and Rates
**Feature Requirements**: see FEAT-004
**PRD Requirements**: FR-13
**Priority**: P1

## Story

**As a** Alex, Admin
**I want** to set a rate per user and override it per project
**So that** amounts are right for each engagement

## Context

Rates change over time and must not rewrite approved history.

## Walkthrough

1. Admin sets Priya's default rate
2. Admin overrides it for project A
3. Rate change with an effective date is saved
4. Reports use the rate in force on each entry date

## Acceptance Criteria

- [ ] **US-008-AC1** — Given a user rate of 100 and project override of 120, when Priya logs time on that project, then the entry amount uses 120
- [ ] **US-008-AC2** — Given an approved entry, when an Admin changes the rate, then the approved entry amount is unchanged

## Edge Cases

- No rate: entry flagged without amount.

## Test Scenarios

| Scenario | AC ID | Input / State | Action | Expected Result |
|----------|-------|---------------|--------|-----------------|
| Happy path | US-008-AC1 | a user rate of 100 and project override of 120 | Priya logs time on that project | the entry amount uses 120 |
| Case 2 | US-008-AC2 | an approved entry | an Admin changes the rate | the approved entry amount is unchanged |
