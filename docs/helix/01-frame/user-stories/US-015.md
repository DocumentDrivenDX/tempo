# US-015: Configure the week start

**Feature**: FEAT-003 — Time Tracking
**Feature Requirements**: see FEAT-003
**PRD Requirements**: FR-25
**Priority**: P0

## Story

**As a** Alex, Admin
**I want** to set which day the week starts on
**So that** the week view and weekly reports match how we work

## Context

The default is Sunday and some teams prefer Monday. The week is a view and a reporting grouping only; it affects no stored data or approval.

## Walkthrough

1. Admin opens settings
2. Admin chooses the week start day
3. The week view and weekly report grouping use the new start

## Acceptance Criteria

- [ ] **US-015-AC1** — Given a new installation, when a user opens the week view, then the week starts on Sunday
- [ ] **US-015-AC2** — Given an Admin sets the week start to Monday, when users open the week view, then weeks run Monday to Sunday
- [ ] **US-015-AC3** — Given approved and pending entries, when the week start changes, then no entry changes state or data

## Edge Cases

- Changing the start affects display and reporting only.
