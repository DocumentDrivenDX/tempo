# US-004: Manage tasks in a project

**Feature**: FEAT-002 — Projects and Tasks
**Feature Requirements**: see FEAT-002
**PRD Requirements**: FR-6
**Priority**: P0

## Story

**As a** Marcus, Project Manager
**I want** to add and archive tasks on my project
**So that** time is labelled meaningfully

## Context

Tasks are labels for time, not a task board.

## Walkthrough

1. Manager adds a task
2. Members can select it when logging
3. Manager archives it
4. It disappears from pickers but stays on history

## Acceptance Criteria

- [ ] **US-004-AC1** — Given a project Manager, when they create a task, then Contributors can log time on it
- [ ] **US-004-AC2** — Given an archived task, when a user opens the task picker, then it is not offered but existing entries keep it

## Edge Cases

- Completing a task with a running timer: timer continues until stopped.
